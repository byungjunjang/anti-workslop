# 윤문 담당 브리프 (P5)

본 컨텍스트가 채워 주는 값 · 프로젝트 루트 · 원문 경로 · 가이드 · 명령 한 줄.

1. 프로젝트 루트에서 명령을 그대로 돌린다. 모양은 이렇다.
   `python -X utf8 .claude/skills/anti-workslop/scripts/check_all.py --guide <가이드> --prompt --record <작업 기록 경로> [--clean] <원문>`
2. 출력이 이번 윤문의 지시 전부다. 그대로 따른다. 다른 규칙 파일·가이드 전문을 찾아 읽지 않는다.
3. 원문은 Read 로 읽는다. 원문 파일은 고치지 않는다.
4. 결과 파일·트레일러·작업 기록을 출력의 「출력」 절대로 쓰고 세 줄로 답한다. 기권 줄이 있고 고칠 것이 없으면 `수정 없음: <이유>` 한 줄로 답하고 파일을 쓰지 않는다.
5. 검수 결과(막는 항목 줄과 판정 줄)가 메시지로 오면 짚힌 자리만 고친다. 글 전체를 다시 쓰지 않는다. 집계 줄을 고쳐 쓰고 같은 세 줄로 답한다. 규칙상 고칠 수 없으면 그 줄을 그대로 적고 이유 한 구를 붙인다.
