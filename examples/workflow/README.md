# 작업 절차와 피드백

[전체 흐름 SVG](01-overview.svg) · [전체 흐름 PNG](01-overview.png) · [검수 흐름 SVG](02-review-loop.svg) · [검수 흐름 PNG](02-review-loop.png)

첫 그림의 01~08, 둘째 그림의 A~H를 사용해 유지·삭제·통합할 단계를 지정할 수 있습니다. 그림은 이번 패치의 실제 절차이며 향후 단순화 제안은 적용하지 않았습니다.

자연어 요청 해석과 가이드 선택은 진행 LLM이 합니다. 코드는 읽기 묶음, 규칙 검사, 변경 구간 후보, 해시·기록 누락 확인을 담당합니다. 재작성 담당은 전체 편집과 자기 대조를 하고, 위험 또는 의문이 있는 문서만 다른 문맥의 담당이 의미를 확인합니다. 독립 담당은 원고를 고치지 않습니다.

## 이번 실행에서 확인한 비용

| 사례 | 재작성 담당 시작·재개 | 독립 검토 시작·재개 | 위험 구간 | 실제 측정 시간 |
|---|---:|---:|---:|---|
| 산업별 AX | 1 | 1 | 360 | 재작성 464.5초, 독립 검토 316.59초 |
| Cowork 마케팅 | 2 | 2 | 91 | 두 번째 독립 검토 48.15초. 전체 시간은 미측정 |
| 메타프롬프팅 | 1 | 1 | 38 + 담당 의문 1 | 전체 시간 미측정 |

횟수는 서브에이전트 시작·재개 도구 호출 기준입니다. 담당 내부 모델 요청 수나 토큰 사용량은 측정하지 못했습니다. 병행 실행이므로 표의 시간을 전체 작업 경과 시간으로 합산하지 않습니다. 기록 시작이 빠진 구간은 추정하지 않았습니다.

## 결과를 읽는 방법

- 마케팅: 최초 독립 검토가 4종의 의미 변화를 발견했고, 두 번째 후속 수정과 재검토에서 해소했습니다. 원문 근거를 확인할 자리표시자 3개는 남습니다.
- AX: 자동 지적 1건과 독립 검토의 7개 사안이 남습니다. 한정 조건, 귀속, 주장 누락, 필요조건 강화, 시제, 확정 수준과 조건, 보호 제목 변경입니다.
- 메타프롬프팅: 자동 지적 1건과 독립 검토의 2개 사안이 남습니다. 원문에 없는 실제 경험 주장과 독자에서 저자로 대상이 바뀐 부분입니다.
- AX와 메타프롬프팅은 후속 수정 두 바퀴에 도달해 확인 필요로 전달합니다. 게시용 완성본으로 표시하지 않았습니다.

위험 구간 수는 의미 오류 수가 아닙니다. 문단의 제목 전환·병합·분할이 추가/삭제 양쪽으로 잡히면서 AX의 검토량이 늘었습니다. **05/B의 위험 추출 범위와 06/E의 검토량**, **수정 두 바퀴 중 자동 검사와 의미 검토의 순서**는 절차 피드백에서 검토할 만한 지점입니다.

SVG는 diagram-design의 swimlane·flowchart 관례로 작성했습니다. 새 모델 API나 외부 서비스는 연결하지 않았습니다.
