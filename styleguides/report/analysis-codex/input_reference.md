# 오캄의 면도날 보고서 스킬을 위한 참고 문헌 큐레이션

## TL;DR
- 최우선 참고 자료 = **『보고서 작성 매뉴얼 〈보고서 잘 쓰는 방법〉』(노무현 대통령비서실 보고서 품질향상 연구팀, 2005.12 완본)** — 개조식·두괄식 원칙의 원천이자 유형별 작성 사례·체크리스트까지 포함, 완본 PDF가 공개돼 있어 스킬의 1순위 학습 코퍼스로 사용 권장.
- 규칙의 근거는 국내는 **국립국어원 공공언어 지침 + 행정안전부 행정업무운영편람**(개조식·명사형 종결·□○-· 기호 체계 명문화), 국외는 **미 육군 BLUF(DA Pam 600-67)·공군 Tongue and Quill(AFH 33-337)·처칠 Brevity 메모(1940)·Amazon PR/FAQ·Minto 피라미드·Toyota A3**에서 확보.
- 공통 원리 6개(결론 먼저·제목이 곧 결론·한 항목 한 정보·숫자 우선·3단 이내 계층·군더더기 삭제)로 수렴 → 아래 스킬 규칙으로 직접 코드화 가능.

## Key Findings
- 한국어 개조식의 "원본"은 노무현 정부 대통령비서실 매뉴얼이며, 시중 베스트셀러 『대통령 보고서』(위즈덤하우스, 2007)가 이를 상용화한 책이다. 매뉴얼 완본 PDF가 온라인에 공개돼 있어 실제 열람 가능.
- 개조식 문법 규칙(명사형 종결 ~함/~임/~요망, 한 문장 개조식, 5W3H, 구체 숫자)은 행정안전부·경기도교육청 공문서 작성법과 국립국어원 자료에 명문으로 존재.
- 영어권 등가물은 이미 성숙한 공개 표준 문서로 다수 존재(군·의회·기업). 특히 CRS In Focus 2쪽 브리프와 Toyota A3는 "1~2쪽 강제 제약"이라는 점에서 개조식과 철학이 동일.
- 기업 내부 문서(삼성 실제 보고서 등)는 비공개 → 공개 대체재(『한 장 보고서의 정석』 26종 예시, Amazon PR/FAQ 공개 예시)로 대체해야 함.

**핵심 개조식 규칙 (근거 있음)**
- 두괄식(결론 먼저) — 대통령비서실 매뉴얼, Minto와 동일 철학
- 명사형 종결: ~함/~음/~임/~요망 (국립국어원 온라인가나다 답변에서 개념 확인)
- 기호 계층: □ → ○ → - → · (행정업무운영편람 표준)
- 한 문장 한 정보, 짧게 끊어 개조식 (경기도교육청 공문서 작성법 verbatim: "문장은 짧게 끊어서 개조식으로 쓴다")
- 구체 숫자 우선: "생산이 증가했다" → "생산이 25% 증가했다" (편람 예시)

### D. 자료 신뢰도 구분
- **검증됨(직접 열람/다운로드 확인):** 대통령비서실 매뉴얼 PDF(전문 확인), NABO 나보포커스 제82호 PDF, 처칠 Brevity 전문·원본 스캔, DA Pam 600-67 PDF, Tongue and Quill PDF, CRS In Focus PDF, Axios Smart Brevity 101 PDF, 행안부 편람 페이지.
- **존재 확인·접근 제약:** NARS 이슈와 논점(DRM 뷰어로 직접 링크 곤란 — 목록 페이지 경유), 국립국어원 PDF(사이트가 자동 접근 차단, 사이트 내 미리보기/다운로드는 사람이 직접 가능).
- **비공개 → 대체재 제시:** 삼성/현대차/토스/배민 등 기업 내부 실제 보고서는 공개본 없음.

## Recommendations
1. **1차 코퍼스(즉시):** 대통령비서실 매뉴얼 PDF + NABO 나보포커스 제82호(4쪽 실제 개조식 표본) + 행정업무운영편람 "문서작성의 일반원칙" 절. 이 3개로 개조식 골격·기호체계·명사형 종결을 스킬 규칙으로 추출.
2. **2차(문장 규범):** 국립국어원 공공언어 자료로 문장 단위 다듬기 규칙(군더더기·이중부정·모호표현 제거) 보강.
3. **3차(논리 골격, 언어 무관):** Minto SCQA + 처칠 Brevity + Toyota A3 7단 + CRS In Focus 2쪽 제약을 "구성 규칙"으로 코드화.
4. **스킬 규칙 초안(벤치마크):**
   - 제목 = 결론 문장(체언 종결). 첫 줄에 결론+핵심 숫자.
   - 계층 최대 3단(□ ○ -), 4단 이상 금지.
   - 한 항목 = 한 정보, 한 줄 40자 이내 지향.
   - 모든 주장에 숫자·근거 1개 첨부(없으면 삭제).
   - 명사형 종결(~함/~임/~할 것/~요망)로 통일.
   - 상세·통계·부연은 별첨(처칠 원칙).
   - 분량 상한 강제: 1쪽 결정문서 / 2쪽 브리프(A3·CRS 방식).
5. **임계값(규칙 변경 트리거):** 한 항목이 2줄 초과 → 분할. 계층이 3단 초과 → 상위 재구조화. 숫자 없는 주장 비율 > 20% → 근거 보강 요구.

## Caveats
- 대통령비서실 매뉴얼 PDF는 개인 블로그(brunch/daumcdn)가 호스팅하는 사본으로, 공식 정부 도메인 원본이 아님 → 인용 시 출처 성격 명시 권장. 매뉴얼 활동은 2005.4~10, 문서 표지는 2005.12.
- 국립국어원·NARS 사이트는 자동 크롤링을 차단하므로 링크가 코드에서 자동 다운로드되지 않을 수 있음(수동 접근은 정상).
- Tongue and Quill(378쪽)·행정업무운영편람은 방대하므로 전체가 아닌 해당 "문서 유형/작성원칙" 절만 발췌해 학습시킬 것.
- 삼성 등 기업 실물 보고서는 확인 불가 → 공개 대체재만 신뢰 근거로 사용.
- Amazon 6-pager/PR-FAQ의 "실제 사내 문서"는 대부분 재현·예시본이며 유출 원본이 아님(Working Backwards 저자 Bryar/Carr 예시가 가장 권위 있음).
