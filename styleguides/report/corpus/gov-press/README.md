# 정부 보도자료 개조식 코퍼스

개조식 검사기(`scripts/check_report.py`)가 사람이 쓴 정부 문서를 막는지 재려고 모은 **사람 코퍼스**다(R1 규칙 검수, 2026-09-23). 가이드 수치(`stats.md`)는 이 폴더에서 나오지 않는다.

- 출처 · 대한민국 정책브리핑(www.korea.kr) 보도자료 목록에서 2026-09-21~23 에 올라온 글 가운데, 공공누리 제1유형(출처표시) 표기가 있고 PDF 첨부가 있는 것. 부처·원문 주소는 `sources.json`.
- 이용 조건 · 공공누리 제1유형(출처표시). 각 페이지가 「텍스트에 한하여」 허락한다. 이 폴더는 텍스트만 싣는다.
- 뽑은 방법 · PDF 첨부에서 표 영역을 빼고 블록 사이를 빈 줄로 나눠 본문을 뽑았다. 보도시점·배포 머리를 떼고 정책브리핑 제목을 첫 줄에 두었다. 줄바꿈은 PDF 그대로라 한 항목이 여러 줄에 걸친다.
- 고른 기준 · □ 1단 항목 셋 이상, 기호 항목 열둘 이상, 항목의 80% 이상이 명사형(-음·-함·체언·수치)으로 끝나는 글. 같은 보도자료가 두 번 올라온 것은 하나만 둔다. 33편.

보도자료는 대외 문서라 내부 보고서와 제목·첫머리 관례가 다르다(H1 제목 길이, H2 첫 3줄). 그 두 규칙의 오탐 근거로는 약하다. 결과는 `docs/superpowers/evals/2026-09-23-r1-rule-audit.md` §6.
